# خارطة التطوير

## 0.1 — الوصف إلى أول مقطع

المطلوب: شاشة وصف، توليد 5 ثوانٍ، متابعة، حفظ، تشغيل وتنزيل. بني هذا الإصدار؛ التوليد الفعلي شرط القبول المتبقي. معيار الانتقال: أول MP4 حقيقي من وصف صاحب المشروع مع نتيجة جودة وتكلفة مسجلة.

## 0.2 — SDK الرسمي والاستئناف بالخلفية

أضيف Node SDK إلى واجهة PHP الحالية، مع الانتظار والحفظ بالخلفية واسترجاع نفس المهمة بعد توقف الخدمة. هذه مرحلة تقنية اكتملت محليًا، ويبقى أول MP4 حقيقي ومعاينته على XAMPP شرط قبول المسار الأساسي.

## 0.3 — صورة + وصف

رفع صورة أصلية، حفظها، إرسالها بمعايير نموذج Image-to-Video، ثم تشغيل المقطع. تأتي بعد التجربة الفعلية لمسار الوصف الحالي. معيار الانتقال: صورة منتج → فيديو مع الحفاظ المقبول على هويته.

## 0.4 — المخرج الذكي

فهم الفكرة العربية وصياغة خطة/توجيه مناسب للمولد. فصل طبقة فهم الطلب عن المزود. سجل النص الأصلي والتوجيه النهائي وتكلفة المخرج. معيار الانتقال: تحسن ملحوظ في النتيجة دون تغييرات غير مطلوبة.

## 0.5 — المحادثة والتعديل والنسخ

توجيه التعديل إلى معالجة محلية أو توليد، وحفظ V1 وV2. البداية بتعديل واحد واضح بدل محرر ضخم. لا تفترض أن المزود يضمن الحفاظ على كل عناصر المشهد؛ قيّم النتيجة فعليًا.

أمثلة التوجيه:

| طلب المستخدم | الأداة المستهدفة لاحقًا |
|---|---|
| غيّر حركة الكاميرا في المشهد الثاني | توليد هذا المشهد |
| أضف السعر من الثانية 8 إلى 13 | تركيب نص محلي |
| كبّر الشعار بالنهاية | تركيب شعار محلي |
| احذف أول ثانيتين | قص محلي |
| رتّب المشاهد | دمج محلي |
| رجّع V1 | اختيار نسخة محفوظة |

## 0.6 — المشاريع والمشاهد

إضافة Laravel وMySQL عند الحاجة الفعلية، مع مشاريع وملفات ومشاهد وعمليات ونسخ ومحادثات. تطوير العامل المحلي إلى طابور مهام دائم متعدد المستخدمين، وتخزين دائم مثل R2، وإعادة المحاولة المنظمة دون تكرار العمليات المدفوعة.

## 1.0 — MVP متعدد المستخدمين

تسجيل ودخول، مشاريع، رفع عدة صور، Storyboard، توليد مشاهد، دمج FFmpeg، مشاهدة، محادثة تعديل، نسخة جديدة وتنزيل، وتسجيل تكلفة العمليات الحقيقية. أضف حماية الوصول وحصص الاستخدام ومراقبة التكاليف قبل فتحه عبر الإنترنت.

الجداول المخططة: `users`, `projects`, `project_assets`, `scenes`, `generations`, `versions`, `messages`, ثم `credit_transactions` و`subscriptions` عند بدء المنتجات المدفوعة.

تبقى لاحقًا: الهوية التجارية، المقاسات المتعددة، التعليق الصوتي، الموسيقى، الاشتراكات. لا نحتاج Timeline أو Teams أو Marketplace أو تطبيق هاتف لإثبات المسار الأساسي.

## معيار نجاح المنصة لاحقًا

صوَر عطر وشعار → إعلان 15 ثانية → تغيير المشهد الثاني وحده → إضافة السعر محليًا → تكبير الشعار → تنزيل مع الاحتفاظ بكل النسخ. هذا سيناريو المرحلة المتقدمة، وليس الادعاء الحالي لإصدار 0.1.
