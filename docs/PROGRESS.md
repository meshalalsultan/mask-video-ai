## ترتيب العمل القادم

1. الرفع والفحوص مكتملان. إعداد الخصوصية الحالي Public؛ يمكن لصاحب المشروع تحويله إلى Private.
2. تشغيل npm ci ثم npm start وXAMPP وضبط المفتاح محليًا. إكمال OAuth مستقل عن مفتاح التطبيق.
3. تنفيذ التجربة رقم 001 في `RESULTS.md`.
4. إذا ظهر فشل، دوّن الحالة والسبب والإصلاح ثم أعد متابعة المهمة نفسها متى أمكن.
5. أضف دعم صورة واحدة فقط بعد نجاح المسار الحالي.
